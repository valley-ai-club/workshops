# Workshop 1, continued: Your GitHub profile & personal website

**Fri, Nov 20, 2026 · SF Valley AI Club** · Instructor: Hua Zhou

If a classmate visited your GitHub profile, could they find something you built and explain how you made it? Today you’ll give them a project to explore, a profile that shows your technical skills, and a personal website to bring it all together.

**Start here:** Open the [student lab](SF_Valley_AI_Club_Student_Lab.html) on GitHub, click **Download raw file** (the down-arrow button), then open the downloaded HTML file in your browser. Keep GitHub open in a second tab. Everything works on a Chromebook.

| Time | What |
| --- | --- |
| 0–15 min | **Pick up from November 6.** Choose a project, create `my-first-repo`, fill in the [About Me README](https://github.com/valley-ai-club/workshops/blob/main/01-github-and-website/about-me-README.md), and make your first commit. Open the commit to see what changed. |
| 15–34 min | **Tutorial 1 · Build your GitHub profile.** Feature a project you’ve worked on, or compare the lab’s ten paper-plane flights. Write a profile README in the repository named after your username. Pin your project, add a clickable toolbox, and invite visitors to guess your result. See [Hua’s profile](https://github.com/Hua-Zhou) for inspiration. |
| 34–53 min | **Tutorial 2 · Publish your personal website.** Download your `index.html` from the lab, publish it with GitHub Pages, and make the headline, colors, and project story your own. If you already have a homepage, add the new design as `portfolio.html` and link to it. |
| 53–60 min | **Swap links.** Give a partner 30 seconds to go from your profile to your website, name one skill you used, and open the work that proves it. Fix one thing they had trouble finding. |
| Office hours | Try an animated name banner or a live last-commit badge. Or add a second project with a screenshot and a sentence about what you contributed. |

## Before you leave

- [ ] I can open my About Me commit in `my-first-repo` and point to a line I changed.
- [ ] My profile shows a tool I used and links to a project where I used it.
- [ ] A classmate tried one of my profile gadgets.
- [ ] My GitHub profile links to my live website, and my website links back to my work.
- [ ] I used a first name or nickname and left out personal contact details and my school schedule.
